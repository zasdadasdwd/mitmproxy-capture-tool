# 外观设置

入口为“设置 → 外观与偏好”。外观即时生效，无需保存其他设置或重启代理。顶部主题按钮显示当前主题名称，点击打开主题菜单；菜单支持点击外部、Escape 和方向键。主题预览经确认后实施，保留原有页面结构和业务操作。

## 完整主题

| 主题 | 默认背景 | 面板 | 强调色 |
| --- | --- | --- | --- |
| 白色 | 冷灰 | 白色 | 蓝色 |
| 黑色 | 炭黑 | 深灰 | 浅蓝 |
| 深海蓝 | 深藏蓝 | 蓝灰 | 浅蓝 |
| 暖纸色 | 米白 | 暖白 | 棕橙 |

文字、边框、悬停、选中、焦点、禁用和提示均使用共享主题变量；成功、警告、错误保留语义颜色。主题在当前浏览器本地保存，刷新恢复，同源页面的主题偏好同步。历史、链路分析、MCP 日志及证书说明使用同一主题变量。

## 本地背景

支持 PNG、JPEG、WebP、GIF，单文件最多 **20 MiB、1600 万像素**。先检查实际文件签名和尺寸，再解码；无效、损坏、超限或存储失败时提示原因，保留原背景。相同文件可以再次选择重试。

“上传 / 替换背景”只读取本地文件并存到浏览器 IndexedDB，不发送到管理服务或其他服务器。原图及动图的静态首帧保存为 Blob；localStorage 仅保存主题、可见程度及动画偏好。不同浏览器、桌面外壳、域名或端口拥有各自的存储，清除站点数据会移除背景，不影响抓包数据库。

背景居中等比铺满并裁切，不重复，不接收鼠标操作。可独立调整工作台面板的 UI 透明度，让图片透过列表空白、侧栏、详情和连接策略底色；文字、按钮、表头、菜单和弹窗保持清晰，菜单与弹窗保持实色。没有图片时恢复主题默认背景。

图片可见程度默认 **30%**：0% 完全隐藏，100% 完全显示。只改变独立底层图片的 opacity，不改变文字或控件透明度；拖动即时预览，刷新恢复。没有背景时禁用滑块和移除按钮。

UI 透明度默认 **20%**：0% 为实色面板，100% 面板底色完全透明；只改变面板背景，不使用整块元素的 opacity，文字和按钮不会一起变淡。该偏好与图片可见程度独立保存、刷新恢复。无图片时禁用，图片可见程度为 0% 时工作台恢复实色。背景操作按钮统一 32px 高、12px 字体和内边距，上传标签不再受通用弹窗 label 的垂直外边距影响。

## 可选内置背景

“启用内置背景 · 随风眨眼”使用随应用分发的动态 WebP，**默认关闭，启动不预加载**。点击后沿用背景透明度、动画开关、刷新恢复和移除；启用失败保留当前背景，替换或移除不删除内置素材。

素材由用户提供的 GIF 无损转码：36,404,403 字节缩至 10,513,478 字节（减少约 71.1%），1280×720、150 帧、总时长 6 秒；逐帧 RGBA 像素一致，原文件未修改。原始 GIF 不重复打包。浏览器已验证默认关闭、手动启用、首帧暂停、刷新恢复和移除后取消选中；逐帧时长与循环次数也与原 GIF 一致。

## 动画与资源

多帧 GIF 和动态 WebP 显示“播放动画”开关，单帧 GIF 与静态图片不显示。关闭时显示首帧，重新开启从原文件恢复播放（从头开始，不保证延续原播放进度）。GIF 首帧保留色表并截断在首个完整图像后；WebP 按 RIFF/ANMF 信息重建单帧并合成画布，参考 [WebP Container Specification](https://developers.google.com/speed/webp/docs/riff_container)。WebP 首帧合成依赖浏览器的 createImageBitmap、WebP 解码与 Canvas；不支持或解码失败时会提示并保留原背景。

未手动选择播放状态时，默认跟随系统“减少动态效果”，系统开启时暂停；用户手动开启或关闭后保存该选择，刷新及系统偏好变化不覆盖手动选择。每页只有一个背景显示实例；替换、暂停、页面隐藏、离开和 0% 可见程度时断开动画源并撤销动态对象 URL，返回后按偏好恢复。临时解码图片和位图使用后清理。
