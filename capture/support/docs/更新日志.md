## 未发布 · 2026-10-08

### MCP 与配套 Skill

- MCP 增加状态/配置/CA 诊断、完整 cURL/requests 代码返回、分页 WebSocket 查询、显式记录控制与抓包中删除，共 21 个工具。
- search_requests 支持结构化 AND/OR 分组；正文读取补充保存状态、采集错误和 HTTP 版本。
- 查询连接池有界，失败信息给出诊断指引；代码输出超限拒绝。准确区分只读、本机状态、外部请求和永久删除注解，不自动重试写操作。
- 新增 tianji-capture Skill、两项 MCP 指南资源及 investigate_request 提示模板；保留重复头、原始字节、截断和来源证据约束。
- Skill 源码在 support/skills，可分发到 Agent；不声称实现 Proxyman 的全部工具、握手认证或全输出自动脱敏。

### 抓包与检索

- 请求/响应正文加入快速搜索与多条件筛选；支持对保存正文的 gzip、brotli、zstd 解码检索。
- 正文查询使用独立读取连接，减少对采集写入的阻塞；正文缺失或截断时不把未知结果当成确定匹配。
- 请求时间与大小支持升序、降序、不排序切换，先排序后分页。
- 修复切换会话后目录刷新定时器不再触发、删除末页后出现空列表的问题。
- 管理进程异常退出后代理主动清理，减少残留进程占用端口。

- 请求地址列以接口路径及 Query 为主，小字显示 Host；根路径和 CONNECT 直接显示 Host。默认宽度优先留给地址，手调列宽继续保留。
- 抓包和重放会话分别保存关键词、范围、面板条件、目录及 AND/OR 分组；返回抓包时恢复来源会话的筛选。
- 外层关键词增加范围选择；内层筛选增加独立关键词，修改内层条件自动清空外层关键词，避免隐含叠加。

### 记录中删除与读取性能

- 抓包和重放执行中可删除选中请求、清空此刻已入库记录；继续接收新请求。删除整个活动批次仍需先停止。
- 删除 ID 保存在 SQLite，迟到的请求、响应和流式更新无法重新创建已删除记录；删除同步清理正文和 WebSocket 消息。
- 清空批次逐行读取详情，避免整批装入内存；旧正文文件清理不占用采集/列表共用锁。
- 合并相同只读请求；切换筛选或详情取消过时读取。读取超时覆盖正文解析前的网络等待，写操作不自动取消。
- 首次查询失败也启动实时连接，后端恢复后可以自动刷新；列表摘要不变时不重建整张表格。
- 修复详情加载时摘要已变化却把旧详情标为新版本的问题，允许下一次刷新继续补齐。

### 请求详情与编辑重放

- 简要详情和完整详情整理工具栏、正文折叠及伸缩区域；按钮区不再参与内容伸缩。
- 域名策略改为浮层，展开不挤压详情；导出菜单补充展开、选中状态。
- 修复详情收起后请求表格宽度不恢复的问题。
- 完整详情支持编辑目标 URL，Query 可解析展示；后端未支持 URL 覆盖时明确报错。
- cURL 和 Python/requests 在详情中打开可复制代码框，批量文件导出继续保留。
- 普通文本正文的 cURL 使用浏览器风格多行命令、重复 `-H` 和 `--data-raw`；只有二进制才使用 Base64 管道，保留原始字节。
- requests 导出支持重复请求头，拆分 Query；Query 未修改时保留原始编码。
- 编辑重放增加 Headers、Query、表单与 JSON 对象表格，支持添加、删除及上下排序，保留原文编辑模式。
- 未修改的 Query 和正文保持原始编码及字节；JSON 重复键、大整数和字段顺序保留。数组、二进制、压缩正文继续通过原文编辑。
- 修复正文格式切换覆盖编辑草稿的问题。
- 重放参数区域改为 Headers / Query / Body 标签切换；紧凑表格约 35px 行高，长值按需展开，修复原文输入框未铺满的问题。

### 大正文与 SSE

- 新增有界异步磁盘保存，默认每流式正文 64 MiB；大正文、无长度响应和 SSE 转发过程中保存，磁盘异常仍继续转发。
- 简便与完整详情增加 SSE 事件预览及已保存原文下载，区分接收中、截断、未缓存、中断和写入失败。
- 下载固定点击时的文件长度，避免 SSE 追加导致 Content-Length 不一致；流式文件更新不再误删已有正文。
- 已通过真实本机 mitmdump 的大正文、分块响应、SSE 转发/保存与停止记录后继续联网测试，以及 SSE 原文/事件界面切换检查。

### WebSocket 消息查看

- 新增双向重组消息增量采集与独立 SQLite 消息表，避免每次传输整个消息历史。
- 简便和完整详情增加 WebSocket 标签、分页、方向、时间、文本及二进制十六进制预览、关闭信息；正文展开后才解码。
- 默认每连接 1000 条/4 MiB、单条 64 KiB，明确提示缺失与截断；删除请求连带清理消息，不重建已删除记录。
- WebSocket 握手及消息不冒充普通 HTTP 重放；旧会话不能补回消息。真实代理已验证双向文本、二进制与正常关闭；600 像素窗口检查无横向溢出。

### 协议与桌面

- 抓包记录新增客户端/上游连接快照：实际 HTTP/ALPN、TLS 状态、TLS 版本、密码套件、SNI、连接 ID、地址及可测得的 TCP/TLS 时长。详情“连接信息”分两端展示；历史缺字段显示未知，不把候选 ALPN 当协商结果。

- HTTP/2 来源请求启用 HTTP/2 协商，目标不支持时回退 HTTP/1.1；HTTP/1 请求使用独立 HTTP/1.1 连接池。
- 重放保存构建后的请求头、原请求快照与实际协商版本，标记协议变化，不宣称保留原客户端 TLS/HTTP2 指纹。
- App 中爬虫工具链接通过系统浏览器打开，避免外部网页替换控制台。

### 请求差异对比

- “更多”菜单支持勾选两条请求对比；两个详情入口支持页面内基准、跨会话对比及重放来源对比。

- 正文限定 64 KiB 预览，单值 512 字符、最多展示 100 项差异；不把预览相同宣称为完整相同，旧后端明确提示未支持的新检查。
- 修复无响应记录对比报错；真实工作台验证两条勾选入口，检查分区选中效果及 600 像素布局。
